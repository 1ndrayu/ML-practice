# ML Mini Projects Collection

A compact set of beginner-friendly machine learning projects — each built in a single Python file, using real datasets and core ML models.

## Projects Included

| # | Project | Model Used |
|--|---------|-------------|
| 1 | House Price Prediction | Linear Regression |
| 2 | SMS Spam Detection | Logistic Regression |
| 3 | Iris Classification | Decision Tree |
| 4 | Digit Recognition | K-Nearest Neighbors |
| 5 | Sentiment Analysis | Naive Bayes |
| 6 | Breast Cancer Detection | Support Vector Machine |
| 7 | Customer Churn Prediction | Random Forest |
| 8 | Customer Segmentation | KMeans Clustering |

## How to Run

1. Clone this repo  
   `git clone https://github.com/yourusername/ml-mini-projects.git`

2. Install dependencies  
   `pip install -r requirements.txt`

3. Run any project  
   `python house_price_prediction.py`

## Requirements

- Python 3.7+
- scikit-learn, pandas, matplotlib

## Purpose

Each project helps you understand a core ML concept by:
- Using a real dataset
- Applying a fundamental algorithm
- Keeping code minimal and focused

Great for learning, showcasing, or building upon.
